# 配達ナビゲーション＆固定ルート管理システム (NaviSystem)

## 1. 概要
1日約100件のルート配送を行うドライバー向けナビゲーション・運行管理システムです。
- **PC管理画面 (`admin.html`)**: CSV取り込み、住所座標変換、コース作成・保存、進捗監視。
- **スマホドライバーアプリ (`driver.html`)**: PWA対応（ホーム画面追加でアプリ化）、本日のコース選択、ピンナビ、ワンタップ配達完了、GPS運行軌跡記録。

## 2. システム構成
```text
D:\navisystem/
├── admin.html              # PC管理画面（CSV取込・コース作成・進捗モニター）
├── driver.html             # スマホドライバー画面（コース選択・ナビ・GPS記録）
├── index.html              # トップポータル（端末に応じた自動ルーティング）
├── manifest.json           # PWA設定（アプリ化・全画面表示）
├── sw.js                   # オフラインキャッシュ用Service Worker
├── sample_delivery.csv     # 動作確認用サンプルCSV
├── test_delivery.csv       # テスト用配達CSV（番地・時間指定・備考入り）
├── SPECIFICATION.md        # 詳細仕様書
└── TASK_BACKLOG.md         # 開発タスクバックログ
```

## 3. 使い方
### 🖥️ PCでの準備
1. `admin.html` を開きます。
2. CSVファイルをドラッグ＆ドロップすると、国土地理院APIにより自動で住所が地図上の座標に変換されます。
3. コース名を入力して「保存」を押すと、ドライバー向けコースとして登録されます。

### 📱 スマホでの運行
1. スマホのSafariやChromeでサイトURLを開きます（自動でドライバー画面が開きます）。
2. ブラウザメニューから「ホーム画面に追加」を行うと、通常のアプリと同じ全画面UIで起動できます。
3. 「本日のお届けコース」から担当コースを選び、「配送開始」を押して運行します。
