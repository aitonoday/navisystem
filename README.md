# 配達ナビゲーション＆固定ルート管理システム (Lively Navi)

## 1. 概要
1日約100件のルート配送を行うドライバー向けナビゲーション・運行管理システム「Lively Navi」です。
- **PC管理画面 (`admin.html`)**: CSV取り込み（配達順対応）、住所座標変換、A➔Bルート探索、手動クリック描画（道路スナップ）、固定ルート作成。
- **スマホドライバーアプリ (`driver.html`)**: PWA対応（ホーム画面追加でアプリ化）、本日のコース選択、順次配達ワークフロー（2択選択 ➔ ナビ ➔ 到着ボタン）、GPS走行軌跡記録。
- **ルート表示カラー仕様**:
  - **動的ルートナビ案内**: **青色** (`#2563eb`)
  - **固定登録ルート (GeoJSON)**: **赤色** (`#dc2626`)

## 2. システム構成
```text
D:\navisystem/
├── admin.html              # PC管理画面（CSV取込・コース作成・ルート描画・進捗モニター）
├── driver.html             # スマホドライバー画面（コース選択・ナビ・GPS記録）
├── index.html              # トップポータル（端末に応じた自動ルーティング）
├── manifest.json           # PWA設定（アプリ化・全画面表示）
├── sw.js                   # オフラインキャッシュ用Service Worker
├── sample_delivery.csv     # 動作確認用サンプルCSV（配達順入り）
├── test_delivery.csv       # テスト用配達CSV（配達順・番地・備考入り）
├── SPECIFICATION.md        # 詳細仕様書
└── TASK_BACKLOG.md         # 開発タスクバックログ
```
